# Testscenario 03 — Innstillinger - Dashbordelementer

:::info[Scenariooversikt]

- **Side:** Innstillinger → Dashbord-elementer
- **Rolle:** Praksiskoordinator (PK)
- **Mål:** Velg hvilke widgeter som skal vises på Dashbord, og bekreft at Dashbord oppdateres.

:::

## Hva denne siden er

**Dashbord-elementer** (under Innstillinger) styrer hvilke widgeter som vises på ditt Dashbord
 (Plasseringsoversikt, Kvoteforespørsler, Oppgaver, Nylige aktiviteter osv.). Å slå et element av eller på trer i kraft
 **umiddelbart** — det finnes ingen egen lagring. Minst ett element må forbli valgt.

---

## Trinn

### 1. Start på Dashbord

Merk deg widgetene som vises nå — inkludert widgeten **Kvoteforespørsler**.

<figure>

![Dashbord før — Kvoteforespørsler synlig](./img/TS-03-dashboard-items/01-dashboard-before.png)

<figcaption>Dashbord før — Kvoteforespørsler-widgeten er synlig</figcaption>

</figure>

### 2. Åpne Innstillinger → Dashbord-elementer

Klikk på **Innstillinger** i sidemenyen, deretter på **Dashbord-elementer**. Hver widget er et kort med en
 avkrysningsboks og et øyeikon; overskriften viser hvor mange av elementene som er valgt.

<figure>

![Standardvalg for Dashbord-elementer](./img/TS-03-dashboard-items/02-dashboard-items.png)

<figcaption>Dashbord-elementer — gjeldende valg</figcaption>

</figure>

### 3. Slå av et element

Klikk på avkrysningsboksen for **Kvoteforespørsler** for å velge den bort. Kortet blir grått, ikonet endres til
 **skjult** (overstrøket øye), og antallet synker (f.eks. *5 of 7 items selected*). Endringen lagres umiddelbart.

<figure>

![Kvoteforespørsler slått av](./img/TS-03-dashboard-items/03-item-toggled-off.png)

<figcaption>Kvoteforespørsler valgt bort — nå skjult</figcaption>

</figure>

### 4. Bekreft på Dashbord

Gå tilbake til **Dashbord** — widgeten **Kvoteforespørsler** vises ikke lenger.

<figure>

![Dashbord etter — Kvoteforespørsler skjult](./img/TS-03-dashboard-items/04-dashboard-after.png)

<figcaption>Dashbord etter — Kvoteforespørsler-widgeten er borte</figcaption>

</figure>

---

## Validering — minst ett element

Du kan ikke skjule alle widgetene. Når bare ett element er valgt, blokkeres forsøk på å velge det bort,
 og en rød melding vises: *"Du må velge minst ett dashbord-element som skal vises."*

<figure>

![Valideringsfeil for minst ett element](./img/TS-03-dashboard-items/05-validation.png)

<figcaption>Å velge bort det siste elementet blokkeres</figcaption>

</figure>
